# Serbify Showcase

Interactive 6-level booking walkthrough and showcase landing page for **Serbify** (Next.js 15, React 19, Tailwind CSS v4, Framer Motion, GSAP, Three.js).

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run start
```

## Deploying to Vercel

1. Push this repository to GitHub as `serbify`.
2. Import the `serbify` repository in Vercel (Next.js framework preset is auto-detected via `vercel.json`).
3. Deploy with default settings (`npm install` / `npm run build`).
